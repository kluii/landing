### CLS flakiness, root-caused

After the size-adjust fix, CLS was still intermittent in CI (0 on runs 45910591818 / 45913767310 / 45915696428, 0.00924 on 45914240097 / 45915877669). The trace shows one LayoutShift of 0.00924 *before* FCP: two text nodes at y≈583/667 move down 44 px when the webfonts apply after the first frame — a race between the preloaded woff2 and first paint, deterministic geometry whenever it loses. Fix: `blocking="render"` on the four font preloads, so first paint waits for the fonts and the swap can never shift layout. `font-display: swap` and the size-adjust values stay (locked stack; residual guard). Verified: run 45916469377 CLS 0, LCP unchanged at 0.25 s.
