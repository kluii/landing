# ADR-0012 — English is the source; French ships; generated app docs are exempt until reviewed

## Status
accepted · 2026-11-26 · Deciders: Wyliam

## Context
Machine-translated technical documentation is a support burden disguised as localisation.

## Decision
English is the source; French ships under `/fr/` with correct `lang`, `hreflang` and typographic apostrophes/non-breaking spaces. Landing, legal, changelog and the site-only docs pages are translated by a human (recorded in the verify file). Generated app docs are exempt from the FR parity test until their translation is reviewed (a page that exists only in English has no `fr` alternate rather than a machine one).

## Consequences
A test asserts EN/FR parity for the hand-written surfaces, with the generated-docs exception documented.

## Alternatives rejected
| Alternative | Why not |
|---|---|
| Machine-translate everything at build | Unreviewed French is worse than none (ROADMAP cut line) |
| English only | The product is French-first |
