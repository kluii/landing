# ADR-0000 — Template

Copy to `NNNN-<slug>.md`, next number, three-word slug. One decision per file. Never edit an accepted ADR: supersede it and say which one it replaces.

## Status

`proposed` | `accepted` | `superseded by ADR-NNNN` | `rejected`
Date: YYYY-MM-DD. Deciders: who actually decided.

## Context

The situation, the constraint that forces a decision, and what breaks if nothing is decided. Facts, not preferences. If a number is involved, measure it here.

## Decision

One paragraph, present tense, active voice.

## Consequences

What becomes easier, what becomes harder, what is now impossible — including the cost: a file that must be touched on every release, a class of bug that is now possible, a check that must be maintained.
