# Documentation

Klui 2.0 is a self-hosted kanban board. A link is the invite, agents read and write
through MCP, and every project closes with a summary generated from the event log.

Start with the [quickstart](/docs/v2/quickstart): one compose file to a working board.

Agents read and write through MCP: <!--@claim:tools--> tools, documented in the [MCP reference](/docs/v2/mcp).
