# Documentation

Klui 2.0 est un tableau kanban auto-hébergé. Un lien suffit pour inviter, les agents
lisent et écrivent via MCP, et chaque projet se clôture par un résumé généré à partir
du journal d’événements.

Commencez par le [démarrage rapide](/fr/docs/v2/quickstart) : un fichier compose vers
un tableau fonctionnel.

Les agents lisent et écrivent via MCP : {CLAIMS.tools.value} outils, documentés dans la [référence MCP](/docs/v2/mcp).

Les pages générées viennent du dépôt de l’application, à la version documentée par ce
site. Les pages écrites pour ce site — introduction au démarrage rapide, FAQ, limites,
migration — sont rédigées ici.
