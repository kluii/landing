# Limits

What Klui 2.0 does not do. Each line is true for the version this site documents.
When a release removes a limit, the line is removed in the same release and the
changelog says so.

- No attachments. Cards hold text, tags, an assignee and a date.
- No calendar or timeline view. The board is the board.
- No mobile app. The web UI works at 390 px; there is nothing to install.
- No presence or live cursors. You see changes, not people.

If one of these is a blocker, Klui is not the right tool yet.
