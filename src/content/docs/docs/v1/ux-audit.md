# 11 — UX audit (Phase 1 of the UX rework)

Baseline taken 2026-11-19 on `origin/dev` (v0.7.0), branch `docs/ux-audit`.
Method: every screen rendered live in Playwright against a seeded dev stack
(3 users incl. the instance admin, one populated board, one archived board,
one expired token), captured in dark + light at 1440×900 and 390×844.
Evidence screenshots: `docs/screenshots/ux-baseline/` (24 curated frames out of 48 captured).
Findings are ordered by **impact on a first-time visitor opening a share link**, then owner flows, then admin.
Behavior bugs listed here were confirmed in code (path cited), not only observed.
